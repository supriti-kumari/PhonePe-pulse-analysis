# PhonPe Pulse: Data Exploration

PhonePe Pulse is PhonePe's open data platform that tracks digital payment trends across India. This project explores its state and district level data (2018 to 2021) using Python.

## Datasets
- State transactions and users
- State transaction type split
- State device (brand) data
- District transactions and users
- District demographics

## What this notebook covers
- Loading and inspecting five datasets
- Shape, data types and summary statistics
- Missing value analysis
- State and district counts

## Tools
Python, pandas, NumPy, matplotlib, seaborn

## How to run
1. Clone the repo
2. Install requirements: `pip install -r requirements.txt`
3. Open the notebook in Jupyter and run all cells

## Source
Data from PhonePe Pulse (phonepe.com/pulse). Completed as a class project.
